# Шахматы для Windows

Настольная программа на C# (WinForms) в стиле Google Material 3 Expressive.

## Возможности
- **Главное меню:** игра с ботом, игра вдвоём на одном экране, выход
- **Бот, 3 уровня:** Новичок, Любитель, Профи; выбор цвета (белые / случайно / чёрные)
- **Анимация:** плавный ход фигур, взятая фигура «тает», пружинные кнопки и карточки с меняющейся формой
- **Взятые фигуры** у каждого игрока и материальный перевес (+N)
- Ходы кликом или перетаскиванием, подсказки возможных ходов, запись партии в нотации (Кf3, exd5, 0-0, e8=Ф)
- Отмена хода (Ctrl+Z), переворот доски (F), ничья, сдача

## Правила (по правилам ФИДЕ)
- Рокировка, взятие на проходе, превращение в ферзя, ладью, слона или коня
- Мат и пат
- Ничья сама: пятикратное повторение позиции, 75 ходов без взятий и ходов пешками, недостаточно материала для мата (в т. ч. только слоны на полях одного цвета)
- Ничью можно потребовать: троекратное повторение, 50 ходов без взятий и ходов пешками
- Ничья по соглашению и сдача

## Сборка
Ничего устанавливать не нужно — компилятор C# входит в Windows. Запустите:

```
build.bat
```

Появится `Chess.exe`. Тесты правил: `test.bat`.
