# Шахматы для Windows

Настольная программа на C# (WinForms): игра против компьютера или вдвоём.

## Возможности
- Все правила: рокировка, взятие на проходе, превращение пешки
- Мат, пат, ничья по правилу 50 ходов, троекратному повторению и недостатку материала
- Компьютер: альфа-бета поиск с оценкой позиции, 4 уровня сложности
- Отмена хода (Ctrl+Z), переворот доски (Ctrl+F), запись партии

## Сборка
Ничего устанавливать не нужно — компилятор C# входит в Windows. Запустите:

```
build.bat
```

Появится `Chess.exe`.
